LAKBAY PILIPINAS — TOURISM WEBSITE
===================================

WHAT'S INCLUDED
- index.html: all website sections and content
- assets/style.css: responsive styling for desktop, tablet, and mobile
- assets/script.js: mobile navigation, destination filters, and demo form confirmations

HOW TO OPEN
1. Extract tourism_website.zip.
2. Open the tourism_website folder.
3. Double-click index.html to open it in a browser.
4. For easier editing, open the folder in Visual Studio Code.
5. Optional: in VS Code, use the Live Server extension and choose "Open with Live Server".

FEATURES
- Responsive navigation
- Destination cards with Beaches / Nature / Culture filters
- Destination links that pre-select the trip inquiry form
- Newsletter form confirmation (demo only)
- Trip inquiry form confirmation (demo only)
- Accessible labels and mobile layout

IMPORTANT NOTES
- Internet access is needed for the remote destination photos and Google Fonts.
- The forms are front-end demos: they do not save data or email submissions.
  To receive real inquiries, connect a backend (for example PHP + MySQL on XAMPP)
  or a form-handling service.
- Destination photos are loaded from Unsplash URLs. Replace these with your own
  properly licensed photos if your school requires locally stored images.
- This is a student project starter website. Customize the content, colors, and
  destinations to match your assigned topic.
